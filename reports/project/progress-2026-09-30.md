# Bonsai | Project progress

30 September 2026 | Model-in-Silicon: Bonsai 2 27B ternary target

## Overall position

**Foundation delivered; first executable slice validated in simulation.** Week 0 is complete, Week 1 is active, and Weeks 2-6 remain backlog. Custom Bonsai FPGA results and full-model token generation are not yet demonstrated.

## Evidence delivered

**Week 0 / PR #1 merged.** Interface and weight-store contracts, image tooling and reproducible environment are delivered. The existing baseline passed **1,332 selected targets**; vendor shell XSIM passed **9/9**. The official AWS F2 example executed **2,264 additions** on physical hardware. That validates the FPGA environment, not Bonsai model execution.

**Week 1 / PR #2 draft.** Model image -> sealed DDR/store -> DOT128 -> mailbox is implemented. The latest local workflow passed **16 steps: 396 native + 6 synthetic cases**, including two expected invalid-code rejections; both full-image readbacks matched. The public SDK transport passed **41 mock checks**. CodeQL passed on validated source `3ee0f99e`; these are software/simulator results.

## Principal risks and boundaries

The current **Bonsai 1.7B Q1_0 fixture is binary sign quantization**; it does not validate the separate **27B ternary** target. Custom timing closure, memory bandwidth and eight physical engines remain unproven. Full Arcilator support and model integration remain follow-on work. Accountable owner: **Rachit Tibrewal**; Codex implements and runs checks with separate automated technical review. Each milestone closes with a reviewed/merged PR, runnable simulator, actual FPGA evidence for its scope and an attached report.
